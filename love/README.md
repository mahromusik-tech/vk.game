# Вдвоём — приложение для пар (Telegram Mini App)

## Что нового в этой версии

- **Выбор игры** во вкладке «Игра»: три режима —
  - 💬 **Вопрос на двоих** — классика, 10 случайных вопросов;
  - 🕯️ **36 вопросов, чтобы влюбиться** — все 36 по порядку, от лёгких к самым личным (оригинальный набор вопросов, написанный для этого приложения, в духе известного психологического формата);
  - 🎯 **Угадай ответ партнёра** — вы одновременно отвечаете сами и угадываете, что ответит партнёр; после обоих ответов — сразу сверка с ✅/❌.
- **Уровень пары**: XP начисляется за игры, отметки активностей, серии и достижения; в Профиле — полоса прогресса.
- **Магазин тем** (вкладка «Магазин»): 5 тем оформления, покупаются за **настоящие Telegram Stars** прямо внутри Mini App, либо выдаются вручную через админ-панель.
- **Скрытая админ-панель** (`admin.html`): поиск пары по коду, выдача темы/достижения, ручная правка XP, список последних оплат.

## 0. Важно про архитектуру Stars-оплат

Telegram присылает подтверждение оплаты (`successful_payment`) **боту**, а не
сайту — сайт технически не может его получить напрямую. Поэтому для реальных
Stars нужны две маленькие серверные функции (Supabase Edge Functions):

- `create-invoice` — создаёт ссылку на счёт (вызывается с сайта);
- `telegram-webhook` — принимает апдейты от Telegram и сама, в обход
  публичных RLS-политик (сервисным ключом), помечает оплату и выдаёт тему.

Без шагов 2–3 ниже кнопки в магазине будут пытаться открыть оплату, но она не
подтвердится — обязательно доведите деплой до конца.

## 1. База данных

SQL Editor → New query → вставьте `supabase-setup.sql` целиком → **Run**.
Скрипт идемпотентный, безопасно перезапускать поверх старой базы. Добавляет:
`game_types`, `pool`/`xp_awarded`-колонки, `themes`, `couple_themes`,
`star_payments`, функцию `increment_couple_xp`, и сиды (3 типа игр, 36 новых
вопросов, 5 тем).

## 2. Edge Functions — без установки чего-либо на компьютер

Dashboard → **Edge Functions** → «Deploy a new function»:

1. Функция `create-invoice` → вставьте код из `supabase/functions/create-invoice/index.ts`.
2. Функция `telegram-webhook` → вставьте код из `supabase/functions/telegram-webhook/index.ts`.

Затем Dashboard → Edge Functions → **Secrets**, добавьте:
- `BOT_TOKEN` — токен вашего бота от @BotFather;
- `WEBHOOK_SECRET` — любая придуманная вами строка (например, длинный
  случайный набор символов) — она же понадобится в шаге 3.

`SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` для `telegram-webhook` уже
доступны автоматически, их задавать не нужно.

(Альтернатива для тех, кто дружит с терминалом: `supabase functions deploy
create-invoice` и `supabase functions deploy telegram-webhook` через
Supabase CLI — делает то же самое.)

## 3. Регистрация вебхука у бота

Один раз выполните (замените `<TOKEN>`, `<PROJECT_REF>` и `<WEBHOOK_SECRET>`
на свои — этот запрос можно выполнить прямо в браузере, вставив ссылку в
адресную строку, либо через curl):

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<PROJECT_REF>.supabase.co/functions/v1/telegram-webhook&secret_token=<WEBHOOK_SECRET>
```

`<PROJECT_REF>` — это `dnkbkytudvhnglnluecc` (видно в вашем `SUPABASE_URL`).
Проверить, что вебхук встал, можно так:
```
https://api.telegram.org/bot<TOKEN>/getWebhookInfo
```

Больше ничего платёжного настраивать не нужно — Stars не требуют отдельного
провайдера, они нативно поддерживаются Bot API (`currency: "XTR"`).

## 4. Деплой сайта на GitHub Pages

Залейте `index.html`, `style.css`, `app.js` в корень репозитория (как и
раньше) → Settings → Pages → Deploy from branch `main` / `/root`.

**`admin.html` и `admin.js` — по желанию.** Если зальёте их в тот же
репозиторий, страница будет физически доступна по прямой ссылке вида
`https://<логин>.github.io/<репо>/admin.html` — она нигде не связана
ссылками из самого приложения, но если репозиторий публичный, это не
настоящая секретность, а «безопасность через неясность». Перед этим:

1. Откройте `admin.js` и замените `ADMIN_PASSPHRASE = "change-me-please"` на свой пароль.
2. Для дополнительной защиты можно переименовать файл во что-то менее
   очевидное (`panel-9f3a.html`) — тогда поменяйте и `<script src="admin.js">`.
3. Если для вас критична настоящая приватность — держите репозиторий
   приватным (GitHub Pages это поддерживает) или заведите отдельный
   приватный репозиторий только для `admin.html`.

## 5. Telegram Mini App

Без изменений: ссылка на GitHub Pages прописывается в @BotFather → Menu
Button (или отдельное Mini App через `/newapp`).

## 6. Как это работает

- **Игра**: вкладка «Игра» показывает карточки трёх режимов вместо одной
  кнопки. Классика и «Угадай ответ» берут случайные 10 вопросов из общего
  банка; «36 вопросов» — все 36 по порядку без перемешивания. Сессия хранит
  `game_type_code`, оба партнёра видят вопросы синхронно как и раньше.
- **Угадай ответ партнёра**: при отправке ответа заполняются два поля — свой
  ответ и догадка о партнёре. Пока не ответили оба — ничего не раскрывается;
  как только оба ответили, сразу показываются оба ответа и обе догадки с
  пометкой ✅/❌ (сравнение по точному совпадению текста без учёта регистра —
  простая эвристика, не идеальна для свободного текста, но работает для
  большинства коротких ответов).
- **XP**: +10 за игру «Вопрос на двоих», +40 за «36 вопросов», +15 за
  «Угадай» плюс +5 за каждое угаданное совпадение в раунде, +5 за отметку
  активности, +20 за разблокированное достижение. Уровень = XP / 150,
  округление вниз. Защита от двойного начисления при одновременном приёме
  события обоими партнёрами — через колонки-guard `current_index` /
  `xp_awarded` (побеждает первый успешный `UPDATE`).
- **Темы**: покупка — `Telegram.WebApp.openInvoice()` открывает нативный
  экран оплаты Stars; после реальной оплаты `telegram-webhook` выдаёт тему
  обеим сторонам через Realtime (по `couple_themes`), поэтому оформление
  меняется у партнёра тоже, без каких-либо действий с его стороны.
  Активная тема хранится в `couples.active_theme_id` и применяется через
  CSS-переменные.
- **Админка**: поиск игрока по коду → видно пару, её XP/уровень и список
  купленных тем → можно выдать тему/достижение или поправить XP вручную,
  плюс таблица последних 20 оплат Stars для контроля.

## 7. Расширение контента

- Новые вопросы: `insert into questions (text, pool) values (...)` — `pool`
  = `general` (классика и «угадай») или `deep36`.
- Новые темы: `insert into themes (code, title, price_stars, emoji, colors)`
  — `colors` это JSON `{"bg":"#..","bg2":"#..","pink":"#..","pinkDeep":"#..","lavender":"#..","gold":"#.."}`.
- Новые достижения: `insert into achievements (code, title, description, emoji)`
  — появятся в сетке достижений автоматически, разблокировать можно только
  вручную (через код в `app.js`/`awardToBoth`) или из админки.
- Новые типы игр: `insert into game_types (...)` — `mechanic` пока
  поддерживает `answer_only` и `answer_and_guess`; для принципиально новой
  механики понадобится доработка `app.js`.

## 8. Что можно доработать позже

- Проверка подписи Telegram `initData` на сервере вместо открытых
  RLS-политик для основных таблиц (актуально с первой версии).
- Возврат/отмена Stars-платежей (`refundStarPayment` в Bot API) — сейчас не
  реализовано.
- История прошлых игр с ответами, полноценный лидерборд по XP.
- Более умное сравнение ответов в режиме «Угадай» (например, по смыслу, а не
  по точному совпадению текста).
