# Вдвоём — приложение для пар (Telegram Mini App)

Файлы: `index.html`, `style.css`, `app.js`, `supabase-setup.sql`.

## Что изменилось в этой версии

- Приложение больше не «одна игра», а полноценное приложение с тремя вкладками:
  **Профиль**, **Активности**, **Игра** — сама игра-вопросник теперь живёт во
  вкладке «Игра».
- Пара теперь создаётся **запросом**, а не мгновенно по коду: вы указываете
  код партнёра и дату начала отношений → партнёр получает уведомление
  (колокольчик сверху) и подтверждает или отклоняет.
- Показывается длительность отношений: «X лет Y месяцев Z дней».
- Меню активностей (Прогулка, Секс, Спали вместе, Виделись, Свидание,
  Подарок) — у каждой свой календарь, можно отмечать дни и видеть текущую
  и лучшую серию (streak).
- Достижения — 6 штук «из коробки» (за первую пару, первую игру, 10 игр,
  серию в 7 и 30 дней, 10 прогулок), приходят уведомлением и всплывающим
  тостом обоим партнёрам одновременно.
- **Исправлена задержка входа в игру/пару**: раньше приложение подписывалось
  на живые обновления только после того, как пара уже была создана — поэтому
  сторона, которая не успела переоткрыть приложение, узнавала о привязке
  партнёра с опозданием. Теперь подписка на уведомления идёт сразу при
  открытии приложения, до всякой привязки, так что запросы на пару и другие
  события приходят мгновенно.

## 1. Обновите базу Supabase

Откройте **SQL Editor** → New query → вставьте `supabase-setup.sql` целиком →
**Run**. Скрипт идемпотентный: его можно спокойно запускать поверх старой
базы, он ничего не задублирует (новые таблицы создаются только если их нет,
сиды вставляются через `on conflict do nothing` / проверку на пустоту).

Новые таблицы: `partner_requests`, `notifications`, `activity_types`,
`activity_logs`, `achievements`, `player_achievements`. В `couples` добавлен
столбец `started_at` (дата начала отношений). На `players.partner_id`
добавлено ограничение уникальности — гарантирует, что у одного игрока не
может быть двух партнёров одновременно.

## 2. Деплой на GitHub Pages

Как и раньше: залейте `index.html`, `style.css`, `app.js` в корень репозитория
→ Settings → Pages → Deploy from branch `main` / `/root`.

## 3. Telegram Mini App

Без изменений: ссылка на GitHub Pages прописывается в @BotFather → Menu
Button (или отдельное Mini App через `/newapp`).

## 4. Как это работает

- **Профиль**: ваш код, приглашение партнёра (код + дата начала отношений),
  после привязки — карточка партнёра и счётчик длительности отношений,
  плюс сетка достижений.
- **Уведомления** (колокольчик): запросы на пару с кнопками «Принять» /
  «Отклонить», подтверждения, разблокированные достижения.
- **Активности**: сетка из 6 карточек, у каждой свой мини-календарь (свайп
  между месяцами стрелками), тап по дню — отметить/снять отметку. Отметки
  общие на пару: их видят и ставят оба партнёра, live-обновление друг у
  друга через Supabase Realtime.
- **Игра**: прежняя механика — 10 случайных вопросов из банка на 50, живые
  ответы, автопереход к следующему вопросу через 3 секунды после того, как
  ответили оба.

## 5. Что можно доработать позже

- Проверка подписи Telegram `initData` на сервере вместо открытых
  RLS-политик (см. предыдущую версию README про безопасность — актуально и
  сейчас).
- История прошлых игр с ответами.
- Больше типов достижений и активностей — таблицы `achievements` и
  `activity_types` можно пополнять прямо через SQL, интерфейс подхватит их
  автоматически.
- Push-уведомления в Telegram-бота при новом приглашении (сейчас всё видно
  только внутри мини-аппа через колокольчик).
